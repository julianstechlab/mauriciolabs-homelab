# MauricioLabs Homelab

A self-hosted homelab built to develop skills in networking, virtualization, Linux administration, security, and infrastructure management.

## Infrastructure

### Firewall
- OPNsense
- VLAN Segmentation
- DHCP Services
- DNS Services

### Virtualization
- Proxmox VE
- Ubuntu Server VMs
- Docker Containers

### Hardware

| Device | Purpose |
|----------|----------|
| Beelink EQ14 | OPNsense Firewall |
| Dell OptiPlex 7060 | Proxmox Host |
| Netgear GS308E | Smart Managed Switch |
| Netgear Nighthawk AX5 | Wireless Access Point |
